## 📌 About the Project

**DishDash** is a recipe finder web application that helps users discover meals quickly and easily. Whether you're looking for inspiration for tonight's dinner or want to explore new cuisines, DishDash provides a clean, intuitive interface to search and browse recipes.

This project was built as a capstone project to demonstrate full-stack or front-end web development skills including UI design, API integration, and deployment.

---

## ✨ Features

- 🔍 **Recipe Search** — Search for recipes by name or keyword
- 🍲 **Browse Recipes** — Explore a variety of meals across different categories
- 📋 **Recipe Details** — View ingredients, cooking instructions, and more
- 🎲 **Random Recipe Discovery** — Get a random recipe suggestion with one click
- 📱 **Responsive Design** — Works seamlessly on desktop and mobile devices
- ⚡ **Fast & Lightweight** — Deployed on Vercel for optimal performance

## 🚀 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v14 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- Git

### Installation

1. **Clone the repository:**

```bash
git clone https://github.com/emmanuelkabange/capstone-project.git
cd capstone-project
```

2. **Install dependencies:**

```bash
npm install
# or
yarn install
```

3. **Set up environment variables** *(if applicable)*:

Create a `.env.local` file in the root directory and add your API keys:

```env
REACT_APP_API_KEY=your_api_key_here
REACT_APP_API_BASE_URL=https://www.themealdb.com/api/json/v1/1
```

### Running Locally

```bash
npm start
# or
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the app.


## 🌐 Deployment

This project is deployed using **Vercel**.

To deploy your own version:

1. Push your code to GitHub.
2. Go to [vercel.com](https://vercel.com/) and import your repository.
3. Add any required environment variables in the Vercel dashboard.
4. Click **Deploy** — Vercel handles the rest!

Live URL: [https://dishdash-recipe-finder.vercel.app/](https://dishdash-recipe-finder.vercel.app/)
